# NOG-OS UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Phase-2 LVGL/TFT UI with the NOG-OS pocket UI: 15 mock screens on a 128×64 mono display, driven by 7 buttons, demo data only.

**Architecture:** `core/` holds portable navigation state (`Router`) and demo data, unit-tested on the host. `app/ui/` draws screens with the **u8g2 C API** (`u8g2_t*`), so the same drawing code runs on the ESP32-S3 and in a host render tool that writes PNG screenshots. `ports/esp32s3/` owns the panel object and buttons.

**Tech Stack:** PlatformIO, Arduino-ESP32, u8g2 2.36.x (`olikraus/U8g2`), Unity (native tests), Wokwi + wokwi-cli, g++ and Python 3 stdlib for the host render tool.

**Spec:** `docs/superpowers/specs/2026-10-14-nog-os-ui-design.md`

**Execution:** Native (the user delegated: "proceed as you like"); one fresh reviewer at the end.

## Global Constraints

- Display: 128×64, 1-bit, u8g2 full-buffer. Wokwi part `board-ssd1306`, I2C, SDA GPIO 8, SCL GPIO 9, address 0x3c.
- Buttons (active-low, `INPUT_PULLUP`, 25 ms debounce): UP 4, DOWN 5, LEFT 6, RIGHT 7, OK 15, BACK 16, TALK 17. TALK emits press **and** release.
- Remove LVGL, TFT_eSPI, ILI9341 wiring and the old Notes/Tasks flow (`core/nav.*`, its tests).
- Timings: frame 400 ms, thinking 2200 ms, pop-up 1400 ms, sleep after 20 000 ms idle on Home, recording cap 30 000 ms.
- All time comparisons wrap-safe (`int32_t(now - deadline) >= 0`); `millis()` wraps after ~49 days.
- Fonts (u8g2 built-ins, all verified present): bold `u8g2_font_helvB08_tr`, body `u8g2_font_haxrcorp4089_tr`, tiny `u8g2_font_4x6_tr`, arcade `u8g2_font_pressstart2p_8r`.
- No commits (user: stay on `main`, uncommitted). No new dependency beyond u8g2.

## Review Focus

1. **Hold-to-talk edges** — TALK release that arrives without a press (or after sleep wake) must be ignored, not jump to Thinking. Test in Task 2.
2. **Back stack depth** — Back on an empty stack must land on Home, never crash or show a stale screen. Test in Task 2.
3. **`millis()` wrap** — deadlines straddling 2^32 must still fire. Test in Task 2.
4. **Text overflow** — every demo string must fit 128 px in its font; a too-long string clips silently on the panel. Checked by the render tool in Task 3 (asserts widths).
5. **Ground wiring in Wokwi** — duplicate `GND.n` wires are silently dropped; button grounds are daisy-chained and `wokwi-cli lint` must report 0 errors. Task 5.
